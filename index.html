DNScope – Open-source for DNS analysis

Publisert 2026-04-21

DNScope is an open source project developed in Python for analyzing DNS traffic from PCAP and PCAPNG files. The project was developed as part of my bachelor's thesis in cybersecurity at Noroff University College, with the goal of structuring and analyzing DNS data in a clear and efficient way. The tool extracts DNS fields from raw packet files, converts the data to a structured format, and performs further analysis using, among others, DuckDB. It then generates tables and visualizations that make it easier to examine patterns in the traffic, including evolution over time, query types, response codes, and geographic distribution. DNScope was applied to the Cloud Telescope IBR dataset and is designed to support three key research questions: the proportion of DNS traffic in IBR, dominant query and response types, and which networks and regions the traffic comes from. The project shows how programming, data analysis, and cybersecurity can be combined in a practical and research-based tool.
